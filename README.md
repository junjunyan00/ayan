## 第一部分:LLM 核心理论(32题)
### 1.1 Transformer 架构与注意力机制(必考⭐⭐⭐)
#### Q1:请详细解释一下 Transformer 模型中的自注意力机制是如何工作的?它为什么比 RNN 更适合处理长序列?
答：
- **自注意力机制**：让序列中每个位置去"看"其他所有位置，计算它们之间的关联程度，然后按关联度加权汇总信息
- **RNN**：一个词一个词顺着读
- **Q\K\V**：Q (Query)	查询	"我在找什么信息？"——这个词想从别人那里了解什么
K (Key)	键	"我能提供什么？"——这个词的"标签/招牌"
V (Value)	值	"我实际携带的信息内容"
- **计算过程分三步**：
第 1 步：算相关性得分，每个词的 Q 去和所有词（包括自己）的 K 做点积，点积越大，说明词 i  越"关注"词 j 。这就是"打量"的量化。
第 2 步：缩放 + Softmax 归一化，​除以根号dk，是为了训练更稳定维度高时点积数值方差会变大，导致 softmax 进入饱和区、梯度消失，缩放让训练更稳定，softmax 后每行权重和为 1，得到正式的注意力权重矩阵。
第 3 步：加权求和，词 i  的新表示 = 按关注度混合所有词的 V。如果"它"对"书包"的注意力权重是 0.7，那么"它"的新向量就主要是"书包"的信息——指代关系被编码进了向量
- **多头注意力机制**：只做一次注意力只能捕捉一种关系。所以 Transformer 把 Q/K/V 投影到 h  个不同的子空间，并行做 h  次注意力。8~128 个头（GPT 系列用 96 个甚至更多）让模型能同时捕捉多种关系模式，最后再拼接融合。
- **为什么比RNN更适合**：

1.**路径长度：O(1) vs O(n)**
RNN：词 t  的信息要传到词 1，必须沿着 hidden state 一步步传递，路径长度 = 序列长度 n 。信息像传话游戏，传得越远越失真。
自注意力：任意两个词直接相连，路径长度恒为 1。第 1 个词和第 4096 个词之间没有衰减链。

2.**长程依赖的梯度问题**
RNN 反向传播要经过 n  步连乘，梯度极易消失或爆炸（即使 LSTM 用门控缓解了，也没根治）。自注意力的梯度路径短且直接，"句首的猫"和"句尾的is"之间的依赖能稳定学到

3.**并行计算**
RNN 天然是串行的：必须算完第 t  步才能算第 t+1  步，GPU 的并行能力大量浪费。自注意力所有位置的计算互不依赖，可完全并行——这让 Transformer 能用海量数据+大算力暴力扩展（scaling law 的工程基础）

4.**直接可解释的"关注模式"**
注意力权重矩阵本身就是一张"谁看谁"的关系图，比 RNN 的黑盒 hidden state 更透明（虽然对可解释性学界有争议，但至少结构上是显式的）。
